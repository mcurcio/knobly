What touching values do under each option

Two plain words can never touch, because touching text is one word (200ms). The rule only matters where a word, a quoted string, a list or a slice meet with no space between them. "Today" and A were run; B and C are reasoned.

Recommended as shown, and fixed in the first build step:
  • Allow * and ? in words so that include /*.conf works. The last page wrongly said draft 2 already accepted it.
  • Reword rasl-bzv.1 for an unclosed [. Lists may span lines, so the error can only be found at the next } or the end of the file, not on the next line.
  • Error positions count characters, not UTF-16 units. ANTLR already reports them that way in both languages.

# Rendered conformance format, v0

The cases for rendered addresses and the order of a diff (spec 7.4 and 7.6), which the load corpus prints only as
people forms. Added in milestone 3 (bead vil-j80). Every binding must give these files byte for byte from the same
input, through the shared driver ([spec/conformance.md](../../spec/conformance.md)). The expected outputs were
derived by hand from the spec, not generated by an implementation; an output that disagrees has found a bug in the
binding or in the spec, never a reason to rewrite the file.

## Inputs

`conformance/rendered/cases.json`: a JSON array of cases, each

```
{"name", "files", "root", "overrides"?, "key"?, "extensions"?, "after"?}
```

as in `conformance/load/format.md`: `key` names a rule in `conformance/keys.json` (sent as data, `spec/conformance.md`
4.3); `after` replaces files for a second load and render, and the output's `changes` are the first render's `diff`
of the second.

## Expected output

```
{"addresses": [[text, people], ...], "changes": [[kind, text, people], ...]}
```

- `addresses`: every directive of the first render in walk order, its address under the key rule: its `text` (the
  address text, spec 7.4: the same bytes in every binding) and its `people form`.
- `changes`: present only when the case has `after`: per change, in `diff`'s order, its kind and its address's
  `text` and `people form`.

## Cases

| Case | What it checks |
|---|---|
| `address-keys` | keys from a value's canonical text (a string keeps its quotes and escapes), address JSON escaping in `text` and in the people form, the occurrence among siblings with the same name and key (`#1`), an absent key (a rule with no value to read, and no rule), an empty key (`connect ""`), a character above U+007F in a key |
| `address-parent-rule` | a rule that names a parent matches only under it; a value index past the values gives no key |
| `diff-order` | removed before added and changed, whatever the after's order; changed by values; a block's directives compared at their own addresses |
| `diff-alone` | a removed directive is listed without the directives inside it |
| `diff-unknown-order` | a directive missing from a container with an unreadable statement is `unknown`, listed in the before's walk order with the removed ones |
| `diff-keyed-move`, `diff-positional-move` | moved lines keep their addresses under a key rule and change by position without one |
| `diff-block-presence` | gaining a block changes a directive |
| `diff-key-duplicate` | a repeated key's occurrence names the copy that went |

## Bytes

As `conformance/format.md`: no insignificant whitespace, every character above U+007F escaped as lowercase
`\uXXXX` UTF-16 code units, one trailing `"\n"`.

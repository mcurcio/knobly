# Written-layer conformance format, v0

The TypeScript and Python low levels (the config as written: documents, statements, values, copies, variables,
resolutions, edits and save) must produce these files byte for byte from the same input. The rules they implement
are in `.claude/design/consumer-api/round12/slices.md` section 2 and `design.md`. The expected outputs here were
derived by hand from those rules, not generated by either implementation; a runner that disagrees with one has
found a bug in itself or in the rules, never a reason to rewrite the file (a rule wrong in section 2 is an erratum).

## Inputs

`conformance/written/cases.json`: a JSON array of cases, each

```
{"name", "needs", "files"? | "fixture"?, "root", "variables"?, "extensions"?, "steps"}
```

- `name`: unique; the expected output is `conformance/written/expected/<name>.json`.
- `needs`: what the case uses. A runner skips a case needing a token it does not implement yet; a finished runner
  implements every token and skips nothing.
  - `include` (the include extension), `snippet` (`snippet` and `use` lines);
  - `values`: `ISetLine.setValues`, `IVariable.setValues`, a value's `replaceWithText`;
  - `statements`: a statement's `replaceWithText` and `remove`;
  - `save`, `quote`;
  - `directive-values`: `IWrittenDirective.setValues`, `IUseLine.setValues`, a value's `remove`;
  - `blocks`: `insertStatements`, `addStatements`;
  - `rename`: `IWrittenDirective.rename`, `IVariable.rename`;
  - `document`: `IDocument.replaceWithText`;
  - `handed`: `IDocumentGraph.setHanded`.
- `files`: path to text, served with `memorySource(files)` / `memory_source(files)`. Or `fixture`: a directory
  under `fixtures/` whose `*.conf` files are served the same way, by path relative to it.
- `root`: the path loaded. `variables`: handed in to the load, by name without `$`.
- `extensions`: absent (none) or `["include"]`. There is no key rule: rendered addresses are positional.
- `steps`: run in order on the one graph the case loads; each gives one entry of the output.

## Expected output

A JSON array with one entry per step. Places are `path:line:col` (0-based line, UTF-16 column, the span's start).
A **copy text** is the load-conformance origin text (`conformance/load/format.md`) of `{written, via}`: for a
statement's copy, `written` is the statement's `place`; for a reference's resolution, the reference's `place` with
the resolution's `copy.via`. A **variable text** is its `place`, `handed <name>` for a handed-in value, or `null`.

### Steps

- `["list"]`:
  `{"files": [[path, [edge, ...]], ...], "edges": [[copy, [spec, ...], [target, ...]], ...],
  "variables": [[name, kind, place | "handed", [reach, ...], [[override, winner], ...]], ...],
  "diagnostics": [[code, origin], ...]}`. `files`: each document (documents order) and its `includedBy()` edges as
  their copy texts. `edges`: `graph.edges()`. `variables`: `graph.variables()`; each `reaches()` and `overridden()`
  resolution as its copy text, an override with its winner's variable text. `diagnostics`: `graph.diagnostics()`.
- `["references"]`: every reference of every document (documents order, then text order, list items and slice
  bounds included) as `[place, declaration, [[copy, winner, [overridden, ...]], ...]]`: its declaration's variable
  text, then each of its `resolutions()` with winner and `overridden` as variable texts.
- `["render"]`: the load-conformance object of `render(graph)` without `files` (`directives`, `unreadable`,
  `diagnostics`), each argument extended to `[text, origin, written, [[reference, winner], ...]]`: `written` its
  place or `null`; each of its `resolutions` as the reference's copy text and the winner's variable text.
- `["texts"]`: each document whose `text` differs from its `source`, as `[path, text]`, documents order.
- `["save"]`: `save(graph, writer)` with a recording writer: what the writer got, `[[path, text], ...]` in batch
  order; `[]` when it was not called.
- `["edit", target, op, ...args]`: the op on the target. Output `["ok"]`, `["ok", [text, ...]]` for an op that
  returns handles (their `text`s), or `["error", name, [[code, line, col], ...]]` with the EditError's name
  (`BadTextError`, `DetachedError`, `NoSetLineError`) and a BadTextError's diagnostics (`[]` for the others).
- `["quote", text]`: `quote(text)`.

### Targets

- `["document", path]`; `["graph"]`.
- `["statement", path, line, col]`: the statement whose name token (the first token of its `place` that is not a
  comment, space or line break) starts there.
- `["block", path]`: the document's body; `["block", path, line, col]`: that statement's block.
- `["value", path, line, col]`: the written value starting there (list items and slice bounds included; a
  reference at its `$`).
- `["variable", path, line, col]`: the variable whose `$name` starts there; `["handed", name]`.
- `["rendered", address, arg, step, "winner" | "reference"]`: render now; the directive at that people address,
  `args[arg].resolutions[step]`, then its `winner` or `reference`.
- `["previous"]`: the target of the previous `edit` step (as it was resolved then: the same handle).
- `["returned"]`: the first handle the most recent edit that returned handles returned.

### Ops

`["setValues", text]`, `["replaceWithText", text]`, `["remove"]`, `["rename", name]`,
`["insertStatements", index, text]`, `["addStatements", text]`, `["setHanded", name, text | null]`.

## Bytes

As `conformance/format.md`: no insignificant whitespace, every character above U+007F escaped as lowercase
`\uXXXX` UTF-16 code units, one trailing `"\n"`.
